# Serviços de rede

O projeto aplicou a ideia de serviços centralizados para integrar computadores e organizar o acesso a recursos.

Compartilhamento de arquivos, usuários, permissões, DHCP e DNS são conceitos relevantes para a arquitetura. Entretanto, a documentação não apresenta cada um deles como configuração original confirmada. Eles permanecem identificados como possibilidades de evolução e reprodução do laboratório.
